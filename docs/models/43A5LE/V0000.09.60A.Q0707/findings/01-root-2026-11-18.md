## Limits and cleanup

This proves one-shot uid-0 code execution by the package manager on this unit.
It does not prove a root shell, boot persistence, or that the result applies to
other models sharing the firmware string. No OTA endpoint, protected path,
stock launcher file, or startup configuration was modified. The temporary
package payload and installer modules were removed from the working tree after
recording this finding.
